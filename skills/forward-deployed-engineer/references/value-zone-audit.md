# 增值区与贬值区审计

本参考用于代码库、产品架构、AI workflow、roadmap 和研发投入组合审计。它综合了“下一代 SOTA 到来时，这项投入会获益还是作废”的判断与 FDE 的现场复利原则。

来源概念：[《从 Spec 驱动转向环境与验证驱动》](https://ata.atatech.org/articles/11020723634)；FDE 的现场到产品复利框架见 [FDE Guidance Book](https://github.com/xdash/FDE-the-Guidance-Book-of-Forward-Deployed-Engineer)。这里是面向工程审计的重新组织，不替代原文。

## 审计单位

按“资产或责任”分类，不按目录整体分类。一个 Pipeline 往往同时包含：

- 提供真实部署结果的发布工具；
- 保存权限与审计状态的控制面；
- 指挥模型逐步行动的长 Prompt。

三者必须拆开判断。只有文件清单、代码行数或命名不能证明价值。

## 四类资产

### 增值区

模型无法从权重中生成、且更强模型会更充分利用的资产：

- 企业内部数据、接口、真实状态和业务语义；
- 构建、测试、部署、设备、浏览器、日志、监控和发布工具；
- 机器可判定的反馈：断言、契约、截图差异、性能阈值、业务指标；
- 专有领域知识、故障经验和约束，且有来源、版本与刷新机制；
- 跨项目复用的集成、评估器、组件和平台能力；
- 能降低反馈延迟、扩大自主循环深度的环境能力。

若能力存在但模型无法调用、结果不结构化或不能回到决策循环，标记为“潜在增值”，行动通常是 `toolify` 或补齐 verifier。

### 贬值区

替代或补偿模型推理能力、容易被下一代模型吸收的资产：

- 通用生码技巧、提示词收藏和模型人格包装；
- 把需求分析、方案拆解、生码、修复固定成细粒度推理顺序；
- 用自然语言指导模型完成可确定执行的环境操作；
- 依赖特殊 marker、固定话术、重复补刀和 Prompt 重放维持成功；
- 针对某个模型版本的上下文技巧、路由话术和行为补丁；
- 无真实数据、运行态或验收信号的演示型脚手架。

“当前有用”不等于“应继续加码”。保留必要兼容层时，也要给出削薄或退出条件。

### 价值保护控制面

它不直接创造业务价值，却让模型安全、可控地进入真实环境：

- 权限、审批、预算、并发和作用域；
- 状态保存、恢复、幂等、回滚和审计；
- 数据边界、合规与高风险人工闸门；
- 失败隔离、超时和可追责记录。

不要把控制面误判为贬值区。需要削薄的是它对“模型应该怎么想”的规定，不是对真实副作用的控制。

### 通用底座

产品必须有，但通常不构成 FDE 护城河：UI 外壳、消息总线、通用 runtime adapter、基础状态管理、普通 CRUD。判断其工程质量，但不要把“必要”写成“战略增值”。当它承载专有环境、反馈或控制能力时，再拆出对应增值部分。

## 六个判断问题

对每项资产逐一回答：

1. **SOTA 效应**：下一代模型更强时，它被放大、基本不变，还是被吸收？
2. **世界信息**：它提供模型自己造不出的真实状态、专有事实或业务反馈吗？
3. **闭环能力**：结果能否结构化回流，让 Agent 决定继续、回滚或停止？
4. **复利能力**：第二个客户或项目是否能以更低成本复用它？
5. **反馈延迟**：它是否把验证从人工等待缩短为秒级、分钟级或可异步追踪？
6. **约束性质**：它是在控制真实风险，还是在替模型规定推理步骤？

缺少代码、运行态、工具 schema、测试、日志或用户证据时，不猜答案；标记 `observe`。

## 常见混合项

| 资产 | 增值部分 | 贬值部分 | 推荐动作 |
| --- | --- | --- | --- |
| Workflow | 调度、权限、状态、审计、高风险闸门 | 固定推理顺序、长 Prompt、话术补丁 | 控制面保留，推理层削薄 |
| Skill | 专有知识、工具 schema、脆弱操作 runbook | 通用技巧、逐步生码配方 | 拆出工具和知识，删除模型常识 |
| MCP 路由 | 内部服务目录、鉴权状态、能力元数据 | 把 URL→工具映射常驻写成长系统 Prompt | 改成注册表与能力发现 |
| 测试 | 真实契约、业务评估集、回归和性能反馈 | 只验证 marker 或历史编排细节 | 投资业务反馈，减少架构锁定测试 |
| Mock | 可回放场景、协议、真实对比、异常注入 | 仅凭 Prompt 生成看似合理的数据 | 保留确定性内核，验证生成输出 |
| Agent runtime | 工具与环境的统一接入 | 模型版本特定补丁 | 稳定接口，隔离兼容层并设退出条件 |

## 输出矩阵

```md
| 资产/责任 | 当前证据 | 分类 | 下一代模型效应 | 缺口 | 动作 |
| --- | --- | --- | --- | --- | --- |
| ... | 文件、调用链、运行态或客户证据 | 增值/潜在增值/控制面/通用底座/贬值/混合 | 放大/稳定/吸收/未知 | ... | invest/protect/toolify/thin/retire/observe |
```

结论必须补充两张清单：

- **继续加码**：下一代模型会放大的环境、验证、知识和复用资产。
- **停止加码或迁移**：应工具化、削薄、设退出条件或直接退役的生成编排投入。
