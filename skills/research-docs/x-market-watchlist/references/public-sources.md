# 公开来源回退

首次周报中，X 主页在网页工具返回 403。搜索找到公开时间线镜像和作者官网。随后按原帖和回复分别翻页，从帖子 ID 和发布时间定位到北京时间的七日窗口，再用作者原文补充论据。

## 搜索与时间线

1. 使用当前环境可用的只读 X 检索入口。可按 `from:HANDLE since:YYYY-MM-DD until:YYYY-MM-DD` 查最新发言，其中 `until` 为排他边界。也可用网页搜索 `site:x.com/HANDLE/status`，搭配时间范围或原帖片段。查询时给时区换算留出边界余量，最终用每条帖子的绝对时间筛选。网页索引适合找入口和交叉核对，结果发布日期和抓取日期都不能代替发帖时间。
2. 如果搜索结果稀疏，查看可公开访问的时间线镜像。例如本次可通过 `https://teapaw.org/HANDLE?filter=posts` 和 `https://teapaw.org/HANDLE/with_replies` 分别读发帖与回复。域名、可用性和覆盖会变，先核对页面作者、最新帖子日期和是否出现分页。网页工具只返回摘要时，可用普通 HTTP GET 读取公开 HTML，使用现有 HTML 解析器提取内容。
3. 在 Teapawt 页面上逐条取 `.timeline-item` 内的 `.tweet-date a`（链接和绝对时间）、`.tweet-content`（发言正文），以及 `.replying-to`、`.quote`、`.retweet-header`（来源关系）。跟随 `.show-more a` 的实际下一页链接。用连续的非置顶帖子判断是否越过窗口起点，跳过混入的旧置顶帖和重复项。分页遇到空响应、重复游标、返回过旧内容或访问错误时，记录受影响的时间段，换另一公开入口核对。
4. 从时间标签、API 时间或原帖 ID 恢复绝对时间。原帖 ID 转毫秒 UTC 的公式为 `(id >> 22) + 1288834974657`，ID 用整数或 BigInt 读取，随后转换为报告时区。X 原帖链接可用已验证的作者及 ID 组成 `https://x.com/HANDLE/status/ID`。只掌握镜像正文时，在覆盖说明中标明镜像取证。

## 长文和上下文

- 优先读作者官网、newsletter 或原视频字幕。本次用 Cowen 官网报告确认 BTC 情景区间及失效条件，用 Citrini Research 公开部分确认 AI 支出、融资及组合调整。帖子分享旧报告时，区分报告发表日期和本期分享日期。
- 引用他人时同时查看外层作者评论和内层原文。比如 Frank 称赞 Flood 的交易，平美股空仓和继续持有 BTC、HYPE 来自 Flood 的披露。Frank 自己说平掉过加密空单，需要引用 Frank 独立发言。
- 如果只找到搜索片段、无法展开图片、原文付费或 Spaces 无可核验字幕，只写已读到的部分并注明覆盖。对过于简短、可能是玩笑或反讽的回复，查看前后文再决定是否收录。
