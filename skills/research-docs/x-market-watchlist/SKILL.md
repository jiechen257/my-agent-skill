# X 市场观点周报

## 确定名单和时间

- 用户给出账号时，以本次指定范围为准。用户说「加上」时，与默认名单合并。未指定账号时读取 [关注名单](references/watchlist.md)。把 X 链接和 `@handle` 归一化，按 handle 去重。仅当用户明确要求长期关注、移除或调整分类偏好时修改名单。
- 优先用用户指定的时间和时区。默认按用户时区取含当天的最近七个自然日，从首日 00:00 到查询时刻。时区缺省时用北京时间。明确写出起止日期和截止时间。
- 若要判断「相比上周有没有变」，查上一期报告里可追溯的原帖或时间窗前的原始发言，并标出对照日期。对照证据不足时，只写本期观点及本期内能核实的变化。

## 查证原始发言

1. 按账号批量检索 X 最新发帖，覆盖原创和带实质观点的回复、引用帖及长帖。检查实际返回的日期跨度，继续翻页直到跨过起点或遇到覆盖限制。
2. 直连受限、时间线过旧或缺页时，按 [公开来源回退](references/public-sources.md) 补齐。跟进作者自己在窗口内分享的报告、视频或长文。以可读正文或可核对的字幕为准。
3. 按帖子 ID 去重。给入选证据保留发言账号、当地日期、原帖链接及正文要点，保留引用帖的原作者。把证据区分为本人观点、本人自述操作、引述他人和报告者归纳。单纯转发、点赞式评论、玩笑和表情只能作背景。对实际持仓只陈述已披露的范围和时点。
4. 检查每个判断的标的、方向、期限和条件。保留原话中的假设、情景、风险和失效条件。短期回调与中期积累可以同时成立。区分市场预期见顶、增速见顶和实际规模下降。

## 输出顺序

1. **本期要点**。标注时区、截止时间和名单，用最多三条概括最重要的有据判断。
2. **按主题比较**。从本期证据归纳主题，优先考虑宏观与流动性、BTC 与加密、美股与行业主题。观点足够集中时可单列 AI、半导体或其他主题。账户增多时按主题归并，先写可对比的观点，再标出作者、时间尺度、分歧理由和观察条件。仅在标的、问题及时间尺度一致时称为共识或分歧。单人提出的新观点可以保留并标明作者。
3. **逐人变化**。每人一行或一条，写最重要的变化和相应依据，例如延续判断、提高或降低信心、改变方向、修改触发条件、披露仓位变化。同一细节只在最适合的位置展开。证据有限时注明「仅核实到本期观点」「未发现可归纳的市场发言」或「覆盖不足」，根据实际情况选择。
4. **覆盖说明**。简述日期覆盖和实际读取的内容类型，标出受限账号、无法读到的回复、付费正文或 Spaces 音频等缺口。

每条重要判断末尾附对应的 X 原帖或作者原文。引用帖涉及第三方仓位时分别链接评论和仓位披露。价格或日期来自当时报告时写明对应时点。不要把二手摘要、市场价格走势或模型推断写成作者自己的话。
