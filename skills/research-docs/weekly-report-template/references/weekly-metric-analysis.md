# 周指标分析规范

本文件仅在周报包含流量、成功率、耗时、错误分布或漏斗数据时读取。目标是把数据写成可解释、可复算的周环比结论，而不是指标清单。

## 周期与可比性

- 默认比较本周与紧邻的上一个等长周期；自然周使用两个连续的周一至周日窗口。
- 两个周期必须使用相同数据源、环境、阶段、类型、结果定义、过滤条件和时区。数据服务使用半开区间时，结束时间取下一周期首日 00:00。
- 看板自带的“同比/环比”可能对应其他基线。除非基线周期与当前报告完全一致，否则从两个周期的绝对值重新计算。
- 查询超时、空路由或字段不可用是证据限制，不得写成 0、无失败或已改善。

## 每项指标的最小信息

有可比数据时，每条核心结论默认包含：

1. 本周值和关键分母；
2. 上周同口径值；
3. 变化量；
4. 对变化的解释；
5. 仍无法确认的边界。

计算规则：

- 数量环比：`(本周 - 上周) / 上周`。
- 比率变化：直接相减并使用 `pt`，例如 `98.39% - 98.45% = -0.06pt`。
- 所有变化值使用显式 ASCII `+` 或 `-` 号：`+20.1%`、`-0.14pt`、`+78ms`。不要用“增长/下降”代替带符号的变化值；零变化写 `0`。
- 成功率必须说明成功量和总量；若分母包含 `failure`、`cancelled`、`unsupported` 等状态，明确列出关键状态量。
- UV 使用数据源的窗口级去重结果。不得把按状态、类型、版本或日期分组后的 UV 相加当成整体 UV。
- 流量增长不等于质量改善；成功率稳定也不等于绝对失败量稳定。两者分别描述。
- 新埋点在对比期中途上线、灰度或切换统计口径时，不计算两个完整自然周的出卡环比。优先核实全量生效时点，取全量后的三个完整日与最近三个完整日，分别计算每日 UV 的算术平均值并标明日期；全量时点未经发布记录确认时，把所选起点标为日志观察到的可比窗口，不写成已证实的全量日期。

## 通用示例：文档产物与订阅漏斗

报告同时覆盖产物链路和会员付费墙时，将 `数据看板 & 分析` 压缩为以下四组，按需合并明细但保留每组口径与关键原因：

1. **产物出卡与预览 UV**：出卡给出可比三日窗口的日均 UV、带符号变化，以及本周整周去重 UV；预览给出本周日均 UV、上周日均 UV、带符号变化，以及两周各自的整周去重 UV 和变化。每日 UV 相加只能用于算日均，不得写成整周去重 UV。
2. **预览质量与性能**：按每日 `success/(success+failure)` 的算术平均值报告整体与低成功率文件格式的日均成功率、上周值和带符号 `pt` 变化；说明主要失败码及其失败分母。性能按成功样本的每日 P50/P90/P99 分别取日均，给出上周同口径值与带符号耗时变化，不能称为整周分位。变化明显时，按格式、版本、平台和原始操作链追查；错误码集中或时间相关性不足以单独证明根因。
3. **文件操作**：分别报告文件编辑保存和格式转换的每日有效终态成功率平均值、上周值及带符号 `pt` 变化。格式转换合并口径先在每一天汇总各格式的 success/failure，再计算当日率；PDF、docx 等差异明显的格式单列。取消和预期不可用不进入有效终态分母。
4. **会员付费墙**：分别报告付费入口曝光、会员页/付费墙曝光、支付页到达和支付成功的周级 UV 与带符号变化；报告入口到支付页、入口到支付成功的阶段 UV 比值及带符号 `pt` 变化。若没有同用户链路、订单标识和回跳完整性证据，明确称为“阶段 UV 比值”，不认定为真实同人转化率。

文案只保留影响判断的数字和一两句原因；所有变化统一写 `+`/`-`，不把尚未验证的发布、需求或修复当作指标变化的既定原因。

## 趋势与波动判断

- 同时看周汇总、每日分母和每日率。不要仅凭折线高低判断稳定性。
- 对低样本指标，展示每日 PV 和非成功状态数。少量失败即可造成明显百分点波动时，写明“低样本放大波动”，不要直接定性为回归。
- 对连续多日低于目标且周环比无改善的指标，写成持续性质量问题；再按错误码、版本、平台或入口拆分。
- 百分位优先比较同一分位的本周与上周值。若只能得到每日区间，明确写“按日范围”，不要把每日分位平均值冒充整周分位。

## 错误与版本归因

- Top 错误至少给出数量、占失败分母的比例和环比变化。错误结构迁移与总体失败率变化分别描述。
- 版本失败量必须结合该版本流量计算失败率；只看失败数量不能判断版本质量。
- 错误码、版本聚集和时间相关性只能形成排查方向。需要关联具体 trace、原始日志或源码路径后，才能写根因。
- 当一个错误需要按前置拒绝、客户端调用或后置渲染拆分时，保留这些层次；不得把同名错误全部归到单一环节。

## 漏斗

- 同时给出各阶段绝对 UV/PV、相邻阶段转化率以及入口到最终成功的整体转化率。
- 阶段转化率使用当前命名周期的绝对值复算；不要直接复用另一个对比列显示的涨跌百分比。
- 订单 ID、请求 ID、支付回跳或上报缺失会影响完整性时，在数据节和遗留问题中标明，不据此声明业务真实转化已改善或恶化。

## 推荐叙事顺序

一组指标按以下顺序压缩成周报文字：

1. 规模：本周值、上周值、环比；
2. 质量：成功率或失败率及 `pt` 变化；
3. 结构：类型、错误码、版本或阶段的主要迁移；
4. 解释：低样本、流量结构或具体错误贡献；
5. 动作：对象、排查或修复动作、可验证结果。

避免把表格逐项复述成正文。只保留影响判断和计划优先级的数据。
