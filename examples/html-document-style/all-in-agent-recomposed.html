四

示例基础与待验证项

从示例资料到可重复运行的任务

维度已有优势转型挑战
产品与端侧示例已具备阅读列表、笔记编辑器和本地演示文件。模拟多步骤任务的失败与恢复，并明确草稿保存的完成条件。
工程能力示例模块包含目录索引、文本切片和草稿导出。补充不同合成资料长度下的任务耗时与结果检查。
迭代模式按演示批次更新样例，每次保留可重复使用的合成输入。检查示例任务是否完成阅读清单和草稿保存，不以页面更新次数判断效果。
组织资产使用自行编写的资料片段、虚构书目和模拟任务记录。区分固定的文件操作与需要人工复核的摘要建议。

核心提醒｜Demo 的速度不等于版本的速度

纸舟演示先实现单条摘录，再用合成批量资料检查重复项、排序和草稿恢复；两类任务分别验收。

需要复核人审 + 迭代
需要人工复核：摘要措辞、资料分类建议和重复条目的合并；演示用户确认后再保存草稿。
暂未覆盖基建可改善
本例尚未覆盖：扫描歪斜页、跨文档冲突和多窗口同时编辑；这些只作为后续模拟任务。
人工决定人的核心战场
始终由演示用户决定：选择保留哪些摘录、如何组织阅读主题，以及是否接受生成的摘要。

行动清单 先试点，再规模化
  1. 示例先行：先写合成书目和预期草稿，再检查检索、摘录与导出行为。
  2. 统一演示步骤：纸舟工坊采用资料输入、任务运行、结果检查三个步骤，每步都保留样例记录。

  4. 结果复核：每次演示检查阅读清单和保存的草稿，不把模拟结果描述为真实用户效果。
