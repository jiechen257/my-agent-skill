维度优势转型 AI Agent 面临挑战
产品 & 端侧PC / 客户端体验、成熟工具生态、C 端用户理解。Agent 编排框架从零补齐；传统测试体系失效；成本与效果保障。

4.3–4.5 回顾、挑战、目标与策略

挑战 1｜集中建设力度不够

好工具覆盖度不够，AI 技巧共享不够，D2C、功能验证和客户端 AI Native 架构存在分散建设。

挑战 2｜高估 AI Coding 的代码质量

千问输入法前期 2 个人几天做出 Demo，但项目化后版本速度没有快起来，投入增加、持续重构、Bug Reopen 率高。

挑战 3｜代码量爆发，掌控力下降

KMP Android & iOS 从 19.98w 行到 39.41w 行，增幅 +97.2%；KMP OHOS 从 19.25w 行到 36.80w 行，增幅 +91.3%。

挑战 4｜编码变快，验证成本没降

编码时间占需求周期不到 30%，剩余 70% 没有提效；Bugfix 和 Reopen 率上升，测试在兜底。

挑战 5｜上下文缺失，卡在最后一公里

Spec、规范和领域知识没有沉淀为 AI 可读资产，Mock、真机验证和日志系统还不够 AI 友好。

五

团队要求

中短期看，AI 时代对人的要求更高

前提：AI 程序员跟传统程序员已经完全不一样了。
定位说明
Agent 工程师建设 Agent 给外部用户使用，对标 WorkBuddy、豆包工作。
AI 程序员应用 Agent 交付功能，优化 Coding Agent，构建 AI 需要的上下文，在领域技能上一专多能。
传统程序员AI 参与度低，传统流程，传统技能。
具体要求 基础、转型、架构
  1. 扎实的基础：判断力、架构能力、沟通能力、学习能力和技术基础。基础不牢，构建起来的产品和工程就如空中楼阁。
  2. 全员 Agent 转型：用 AI 重新设计团队和个人核心流程，新流程以 AI 为前提，理解并优化 Agent。
  3. 全员具备架构能力：运营业务组做全栈尝试，客户端做跨端实践，一人两端、三端。
总结

大模型是一场智力革命。旧时代的复利开始下降，新时代的复利已经开始；新的产品形态、团队形态和社会形态都在围绕它变革。
